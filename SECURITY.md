# Security

## Supported versions

Only the newest release of md-chunk-lite gets fixes.

## Report a problem

Please do not open a public issue for a security problem.

Use GitHub's private report form instead:
https://github.com/tidybytetools/md-chunk-lite/security/advisories/new

Tell us what you found and how to make it happen again. We will reply as soon as we can, and we will credit you if you want.

## What this tool does

md-chunk-lite runs on your own computer. It does not send your files anywhere and never uses the internet. Only one MCP tool writes a file (`save_chunks_jsonl`), and it only writes a `.jsonl` file. It never changes your Markdown files. It has no accounts, no API keys and no tracking.
